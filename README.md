# Tuhina's Secret Birthday Gift

A mobile-friendly birthday surprise website inspired by the supplied reference video.

## Preview locally
Open `index.html` in a browser. For the secret passcode screen, enter **0609** (6 October, DDMM).

## Publish with GitHub Pages
1. Create a repository on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder (keep the folder structure).
3. In **Settings → Pages**, choose deploy from the `main` branch and `/ (root)`.
4. Share the published link with Tuhina.

All images in `assets/` are cropped from the reference video you provided.
